# SalesInsight PY

Mini projeto de análise de vendas desenvolvido em Python.

## Objetivos

- Gerar dataset sintético de vendas
- Realizar limpeza e tratamento de dados
- Calcular métricas de negócio
- Segmentar clientes
- Gerar gráficos analíticos
- Exportar relatórios CSV e JSON

## Tecnologias Utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn

## Estrutura do Projeto

salesinsight.py
vendas.csv
outputs/
planejamento/

## Funcionalidades

- Pipeline de processamento de dados
- Engenharia de atributos
- Estatísticas vetorizadas com NumPy
- Programação Orientada a Objetos
- Exportação CSV e JSON
- Geração de gráficos
